Playback notes (November 2026):
- Preview the site through Open-Preview.command (http://127.0.0.1:8765), not by opening index.html as file://. YouTube requires an HTTP Referer for embedded playback; the pages now declare the site origin and each YouTube iframe sends it.
- YouTube videos must also allow embedding in the uploader settings. If an individual video has embedding disabled or is region/age restricted, the player cannot override that restriction.
